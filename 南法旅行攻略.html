01

抵达，先慢下来

9月28日 · 周一 / Helsinki → Nice

  1. 落地后
    赫尔辛基入境与转机评估

    先完成必要边检、安检并确认下一程登机信息。不要把“20–30分钟完成入境”当保证；根据实际落地和排队情况决定是否进城。

  2. 上午
    可选：市中心轻量散步

    中央车站—参议院广场—港口。教堂以外观为主，营业时间未经核实的商场与餐厅不做硬预约。不安排强制四点打卡。

  3. 起飞前
    留足返回机场时间

    建议按下一程起飞前约3小时回到机场规划，另计市区返机场交通；这属于保守安排，不是芬航统一要求。

  4. 尼斯抵达
    机场 → Grand Arénas → 酒店

    尼斯机场官网确认T2—T1—Grand Arénas电车区间免费；乘2号线往Port Lympia方向，在Grand Arénas下车后步行到酒店。建议在Grand Arénas电车站机器购买7天Sud Azur Explore，勿误选仅尼斯市内7天票。酒店附近吃饭和休息。想进城吃饭须单独预留往返交通，不再把市中心餐厅写成步行可达。

今日只做一个决定

赫尔辛基进城取决于实时情况，累了就留机场。抵达尼斯后不再追日落点位。

芬航官网：9/28 05:55抵达HEL，15:55续飞，18:25抵达尼斯T2。去程有10小时计划中转，实际进城仍取决于边检、行李与精神状态。

02

尼斯，早市与海岸线

9月29日 · 周二 / Nice

  1. 08:30起
    早餐后出发去老城

    电车加步行安排足够缓冲。尼斯旅游局2026年表列食品市场周二06:00–13:30；9/29周二安排上午逛市集。花市与食品摊收摊时间不同，不把午后当成食品市集主时段。

  2. 上午
    Cours Saleya → 老城 → 城堡山

    市集慢逛，沿石巷上山。电梯若停运，以步行和体力为准；不把“光线最佳时刻”写成承诺。

  3. 12:00左右
    在老城附近吃午餐

    优先选当前位置附近、当天开门的店。正式用餐给60–90分钟，不为一间网红餐厅横穿市区。

  4. 下午
    马塞纳广场、海边，少量购物

    购物控制在约一小时；集中采购留到CAP3000。海边休息、冰淇淋、散步，按天气调整。

转场，住进另一段海岸

9月30日 · 周三 / Nice → Juan-les-Pins · Antibes

    从 Nice Saint-Augustin 查询西行 TER；目的地为26 Avenue Gaston Bourgeois的Hotel Journel，具体下车站优先选择Juan-les-Pins。先寄存行李，不保证上午提前入住。

  2. 12:00左右
    昂蒂布老城午餐

    将餐厅、博物馆和港口放在同一片区，减少下午折返。

  3. 下午
    老城 → 毕加索博物馆 → 城墙与港口

    市政府官网：9月16日至次年6月14日10:00–13:00、14:00–18:00，周一闭馆，售票处提前30分钟关闭。9/30周三建议14:00后参观；临时闭馆则改老城散步。馆内不接收大件行李，先在酒店寄存。海角机位不在今天额外往返。

  4. 傍晚
    回酒店办理入住，附近晚餐

04

戛纳半日，海角半日

10月1日 · 周四 / Cannes · Cap d’Antibes

  1. 上午
    坐火车到戛纳，漫步影节宫与旧港

    发车站选择Juan-les-Pins，建议提前到站。红毯和活动场地可能临时封闭，不承诺能站上指定台阶。

  2. 中午
    午餐，返回昂蒂布片区

    火车接公交或其他接驳到海角步道，门到门时间包含候车，不只计算列车运行分钟数。

  3. 下午
    海角步行，量力选择长度

    旅游局路线：Avenue André Sella的Garoupe海滩停车场起步，沿海岸经过Eilenroc附近，再经Avenue Mrs LD Beaumont及Avenue de la Tour Gandolphe闭环。约5公里、2小时是官方步行参考；拍照休息另加余量。恶劣天气官方会关闭步道，当天看告示，关闭则改市区海边。

  4. 天黑前
    完成步行并返回可乘车区域

    不再使用没有地图的“6→7→9→10”编号；不为拍日落走夜路。雪山机位仅在天气和路线都合适时加入。

随身小物

防滑鞋、水、薄外套、充好电的手机。今日目的不是走完所有海角，而是留一段舒服的海岸记忆。

05

山城与柠檬色的海

10月2日 · 周五 / Èze → Menton → Nice

  1. 早上
    退房，先到尼斯机场酒店寄存行李，再去埃兹

    先乘TER到Nice Saint-Augustin，步行至当晚的Holiday Inn Express Nice Grand Arénas寄存；需事先确认酒店可在入住前寄存。不要拖行李爬山城。若寄存或交通耗时较长，改为摩纳哥＋芒通，或只选一个目的地。Èze-sur-Mer 火车站位于海边，与 Èze Village 山城不同。建议乘10:14–10:39的TER到Èze站，按地图平台11:25的83路上山；14:05下山、14:40–15:06 TER赴芒通。公交见交通节的来源与复查说明。

  2. 上午
    石巷与植物园

    植物园官网：10月每天09:00–18:30，成人€10/人。留足石巷和花园步行时间，建议12:00左右午餐；香水工厂为可选，不挤占14:05下山公交。

  3. 午间
    正常吃午餐，再前往芒通

    根据已确认的接驳选择在埃兹或芒通用餐，不把正式午餐拖至15点。

  4. 下午
    芒通老城与 Sablettes 海边

    留时间坐下来喝东西。各地图链接用于定位区域，不能替代现场入口、楼梯与步行路线判断。

  5. 傍晚
    返回尼斯机场片区酒店

    查询到 Nice Saint-Augustin 的可行车次与停站；若在市中心晚餐，另计去酒店交通。不承诺18:45办好入住。

摩纳哥如何加入？

更稳妥的方式是替换埃兹，变成“摩纳哥＋芒通”。若坚持三站，摩纳哥只能短停一个片区，必须重新匹配班次。

本版删除罗克布吕讷。回程向尼斯行驶，海侧通常在前进方向左边。

最后一杯咖啡，然后回家

10月3日 · 周六 / CAP3000 → NCE → HEL → Shanghai

  1. 早餐后
    退房，确认行李寄存

    购物时尽量轻装。CAP3000官方列Auberi周一至周六10:00–20:00、周日13:00–19:00；本次10/3是周六，按10:00后到店安排，临时调整以门店公告为准。

  2. 上午至午后
    CAP3000，按清单购物

    尚美先确认货号、尺寸、库存、欧元成交价与净退税金额。尽量提前联系，避免最后一天才发现无货。

  3. 按客票倒排
    取行李，前往正确航站楼

    铁路不直接进入航站楼。购物结束到机场的总时间应包含步行、候车、取行李和机场接驳。用户确认19:10从尼斯乘AY1604。建议16:10前抵达尼斯T2；如需处理托运行李内商品的海关手续，应再提前。购物结束时刻需按酒店取行李和接驳实际用时倒排。

  4. 赫尔辛基
    退税海关验证 → 出境边检 → 登机

    随身法国退税商品按最终离欧点办理。先问清海关位置和登机口，不离开空侧去追现金退款柜台。

购物与航班的优先级

返程登机优先。不能把“1小时45分钟转机”理解为有完整105分钟购物或退税；实际还要扣除下机、步行、边检和登机截止时间。

买好这张通票后，火车还要单独买票吗？

持有效Pass Sud Azur Explore乘坐覆盖范围内的TER，无需重复购买单程票。请核对完整票名、有效期及每人的乘车凭证；购票收据不等于卡内已载入有效票种。SNCF官方说明此票载于匿名智能卡或个人ZOU卡。

  1. 出发前查询日期、方向、TER车次与停靠站。
  2. 带好载有有效通票的实体卡，按该卡要求验证；首次乘车可请站务确认操作。
  3. 保留卡供查票；没有闸机不代表无需有效乘车凭证。
  4. 不要乘坐TGV INOUI、OUIGO或其他不在通票适用范围内的列车；通票不是所有法国火车的通用票。

本次尚未查到游客通票在TER站的完整官方验证条文，不能承诺“不用刷卡”。时刻核验与是否需要另买票是两件事，仍须查看当日运行和施工信息。

法国海关官方规则

购物时就把单据拿对

通常需年满16岁、常住欧盟外、在法国或欧盟停留少于6个月；商家必须愿意办理退税。同一商号或商号集团最多3天内购物金额严格超过€100。不是任意商店小票都能合并。

出示护照原件及必要的居住证明，领取出口退税单，核对姓名、护照资料、货号、金额和退款方式。只有购物小票不足以替代退税单。

验证期限为购买月份之后第三个月月底前；仍应在本次实际离欧时办理。

两个人，€800现金够吗？

CASH & CARD

机票、住宿与珠宝主要刷卡时，€800作为六天现金储备通常充裕；若所有日常消费都只用现金，则应按实际餐饮与购物预算核算。

这笔钱怎样分配

下面是分配建议，不是当地报价：€300日常零星消费、€200部分餐饮、€100交通或临时接驳备用、€200应急留存。可刷卡的大额支出优先刷卡，现金不必全部花完。

两人六天平均约€133/天。去程赫尔辛基的支出及返程延误开销也要计入总预算。

带现金，也带支付备选

以€10、€20、€50面额为主，准备少量硬币；两人分开放，日常钱包只留当天预计用量。至少准备一张可用的国际银行卡，并提前核对境外支付设置及额度。

尚美不纳入€800日常现金预算。选择欧元结算前看清支付终端与发卡行费率，不默认商户人民币换算更划算。

现金储备≠全程预算未计入尚未支付的住宿费、珠宝、大额购物或频繁打车。若你们想把两人全部餐饮、景点和交通也压在€800内，需要再单列每日预算，不能直接沿用“现金够用”的结论。
